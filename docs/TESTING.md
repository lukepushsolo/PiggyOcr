# 人工测试清单

自动化已覆盖：Core 单测、左/中/右键端到端、快捷键录制。
以下项目每轮发布前人工过一遍，记录系统版本、DPI、显卡。

## 环境

- Windows 10 22H2 / Windows 11 x64（至少各一台）
- 干净机器：未安装 .NET、VC++、CUDA
- 单屏 + 多屏（不同 DPI 更佳）
- NVIDIA / AMD / Intel 核显各一台（至少两种）

## 1. 解压即用

1. 新建空目录，解压 app zip。
2. 解压任一模型包到同一目录。
3. 双击 exe：托盘出现，无报错弹窗；任务管理器只有一个进程。
4. 关闭程序，托盘图标消失。

## 2. 取字主路径

1. `Win+Shift+O`：屏幕变暗、光标旁出现放大镜、底部提示条。
2. 滚轮缩放放大镜；拖选松手 → 文字进剪贴板 → 结果窗出现。
3. 结果窗编辑后点窗外：不关闭；`Esc` 关闭；`Ctrl+Enter` 复制并关闭。
4. 未修改时点窗外：自动关闭。
5. 双击（不拖）：全屏识别。
6. 右键 / `Esc`：取消，不复制。

## 3. 鼠标动作

- 左键 = 识别并编辑；中键 = 识别并复制后关闭（气泡）；右键 = 取消。
- 装有 Quicker / 鼠标手势时：被注册为长按手势的键可能被全局钩子抢占；
  确认右键短按仍可取消，长按可能弹第三方面板。
- 在设置里改动作后立即生效。

## 4. 设置

- 快捷键录制：点击输入框，按 `Ctrl+Shift+K`，显示并生效；旧热键失效。
- 被占用的组合（如 `Ctrl+C`）提示更换。
- 模型档位切换：tiny / small / medium 切换后后端显示更新，识别正常。
- 自动复制、开机自启开关立即生效。
- 设置写入 exe 旁 `PiggyOcr.json`；只读目录回退 `%LOCALAPPDATA%`。

## 5. 自启与更新

- 开启自启 → `HKCU\...\Run` 出现 `PiggyOcr`；关闭后消失。
- 重启后自动进托盘。
- 手动「检查更新」打开 Release 页；断网时静默失败。
- 有新版本时气泡提示，点击打开下载页。

## 6. 模型与回退

- 删除 `models` → 首次运行引导窗；打开目录 / 下载页可用。
- 损坏 `det.onnx` → 明确报错，不崩溃。
- 无独显 / 禁用 DML → 日志有 fallback 原因，CPU 可识别。
- tiny 不支持日文（用日文图验证 small / medium）。

## 7. 显示与兼容

- 100% / 125% / 150% / 200% 缩放：蒙层、选区、放大镜、结果窗位置正确。
- 多屏（左/右/上/下排列）：跨屏框选可用；混合 DPI 不错位。
- 深色 / 浅色系统主题：设置页与结果窗跟随。
- 1280×720 与 4K：设置窗完整显示（可滚动）、结果窗不超出工作区。

## 8. 已知限制

- 独占全屏 / DRM 内容黑屏（系统限制）。
- 管理员权限的前台窗口上，普通权限的全局热键无效。
- HDR 屏颜色可能失真。
